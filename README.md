A deterministic Python program that writes the single sentence a house cat would say in its own defence after sweeping a glass off the table, to `/output/entry.txt`. The cat's case: the glass had been squatting on its sunspot for three days, so it served the glass an eviction notice. No apology, no confession — pure feline self-interest.

## Run it

```sh
python3 main.py
```
